# 六年級數學王者競技場

115 學年度國小六年級數學互動競賽第一版。純 HTML、CSS、JavaScript，沒有帳號、資料庫、付費 API 或後端。

## 智慧音效系統

首頁右上角的「🎛 音效台」是教師專用控制面板，可手動播放鼓掌、熱烈歡呼、鼓勵、勝利或隨機音效，調整音量（最高 70%），以及立即停止全部聲音。

「啟用遊戲自動音效」預設關閉。教師勾選後，答對、連續答對 3 題、全員答對、答錯、倒數 10 秒、換組與結算會自動播放相應音效。瀏覽器基於安全規則，第一次使用必須由教師點擊面板中的音效按鈕或勾選自動音效。

音效檔位於 `dist/assets/audio/`，增加鼓掌聲的方法請見該資料夾的 `README.md`。

閃電擂台每次按下「答對加分」都固定播放 `applause-01.mp3`（原始檔 `freesound_community-applause-75314.mp3`），不需要另外勾選自動音效；上方總音效開關仍可控制靜音。

數學寶箱王每次按下「答對加分」都固定播放 `applause-02.mp3`（原始檔 `pwlpl-applause-sound-effect-521104.mp3`），同樣不需要另外勾選自動音效。

## 第一版功能

- 單人「數學寶箱王」、雙人「閃電擂台」、三人「三勇士打魔王」
- 8 個上學期單元、簡單／普通／困難，共 128 題原創測試題；每單元普通與困難各 7 題
- 題目隨機抽取，同一輪題庫用完前不重複
- 教師公布答案、判分、跳題、開始／暫停、下一組
- 30／45／60／90／120 秒計時，全螢幕、鍵盤操作、音效與減少動畫
- 寶箱稀有度隨機獎勵、擂台速度名次獎勵、魔王 HP 與傷害回饋
- 可設定 3／5／8／10／15／20 個總回合；每回合加分或答錯扣 50 分，跨回合保留累積總分
- 最後一回合自動顯示完整排行榜與總分結算，並可匯出 CSV
- 每次答對都播放短掌聲，並由瀏覽器隨機朗讀中文稱讚；音效開關可一併關閉
- 每次答錯會播放柔和提示音並朗讀「再接再厲」等隨機鼓勵語，不使用挫折性音效
- 三勇士模式在魔王 HP 首次歸零時播放加強版歡呼與勝利語音；每回合及整場都記錄擊敗魔王數，CSV 亦包含紀錄
- `localStorage` 保存設定與戰績；匯出 UTF-8 CSV、清除戰績

## 本機開啟（新手方法）

直接雙擊 `dist/index.html` 即可。若瀏覽器限制本機功能，可在本資料夾開啟 PowerShell，執行：

```powershell
npx serve dist
```

再開啟終端機顯示的網址。第一次使用 `npx serve` 可能需要網路下載工具。

## 教師操作

1. 選遊戲、單元、難度、秒數，輸入學生或隊伍名稱。
2. 按「開始新回合」，學生在黑板列式。
3. 按開始計時；完成後公布答案。
4. 先按選手卡或 1／2／3 選人，再按答對或答錯。
5. 按「下一組」保存本回合並輪替參賽者。

快捷鍵：`Space` 計時、`A` 答案、`1/2/3` 選人、`+/-` 判分、`S` 跳題、`N` 下一組、`F` 全螢幕。

## 更新題庫

編輯 `dist/data/questions.js`。每題需包含 `id`、`unit`（1–8）、`difficulty`（easy/normal/hard）、`prompt`、`answer`、`explanation`。改完執行：

```powershell
npm test
```

## GitHub 與 GitHub Pages

1. 在 GitHub 建立空白 repository，例如 `math-arena-115`。
2. 把本資料夾內所有檔案上傳，或用 Git 提交並推送。
3. Repository → **Settings** → **Pages**。
4. Source 選 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/docs` 需要先把 `dist` 改名為 `docs`；或使用 GitHub Actions 發布 `dist`。
5. 最簡單做法：把 `dist` 內的檔案放在 repository 根目錄，再選 `main / (root)`。

## 人工確認清單

- 教師逐題核對翰林版 115 學年度實際授課範圍與用語。
- 以教室投影機實測 1920×1080 的最遠座位可讀性。
- 以實際班級名單跑完一次換組順序與同分加賽流程。
- Chrome、Edge、Safari 各試玩至少 10 回合；確認音效符合校內設備音量。
- 目前是 128 題功能題庫；正式使用前仍建議逐題由教師審核，並逐步擴充至每單元 30 題。
